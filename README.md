# وعيي درعي — الوقاية من المخدرات والمهلوسات
برنامج تحسيسي تفاعلي للأطفال والشباب — **ديوان قطاع الشباب والرياضة**.
واجهة عربية RTL كاملة، تعمل دون خادم ودون إنترنت (بعد أول فتح)، ولا تجمع أي بيانات.

## التشغيل
```bash
# أي خادم ملفات ثابتة يكفي. مثال:
python3 -m http.server 8080        # ثم افتح http://localhost:8080
```
- لا حاجة إلى تثبيت أو بناء. افتح `index.html` عبر خادم (خدمة الملفات الثابتة شرط لتفعيل «العمل دون إنترنت»).
- للنشر على GitHub Pages: ارفع محتوى المجلد كما هو إلى مستودع، ثم فعّل **Settings ← Pages ← Deploy from a branch ← main**.
- نسخة الملف الواحد (للإرسال أو الفتح المباشر): `python3 tools/build.py` ← `dist/standalone.html`.

  js/

    app.js                 المحرّك: المحطات، المسابقة، السجل، الصفحات، البحث، الإشعارات
    pwa.js                 تسجيل خدمة العمل دون إنترنت
  img/                     الشعار الرسمي بمقاسات، الأيقونات، صورة المعاينة، التوقيع
  fonts/                   خط احتياطي مضمّن (الخط الأساسي Cairo يُحمَّل من Google Fonts)
manifest.webmanifest · sw.js · intro.mp4

tools/                     gen_tokens.py (توليد الألوان) · build.py · أدوات الاختبار

## تغيير الشعار أو الألوان لاحقًا
**الشعار**: استبدل ملفات `assets/img/logo-*.webp` (المقاسات 64 · 96 · 192 · 256 · 512، مربعة 1:1 وخلفية شفافة) وأيقونات `icon-*.png` و`apple-touch-icon.png` و`og.jpg`. المسارات ثابتة في الشيفرة فلا يلزم تعديل شيء آخر.

**الألوان**: افتح `tools/gen_tokens.py` وعدّل القيم الأربع في `BRAND`، ثم شغّل `python3 tools/gen_tokens.py` ليُعاد توليد `tokens.css` بكل الدرجات المشتقة. لا توجد ألوان خام في بقية الملفات (إلا ألوان الرسوم الصغيرة داخل `app.js` وهي من نفس السلالم).

**الخط**: غيّر `--font` في `tokens.css` ورابط Google Fonts في `index.html`.

## الاختبار
```bash
python3 tools/test_ui.py              # 38 فحصًا وظيفيًا (تنقل، بحث، إشعارات، لوحة، هاتف، العمل دون إنترنت…)
python3 tools/test_session_tools.py   # 28 فحصًا لأدوات الحصة (الاستوديو، النبض، الإدارة، التعزيز، المطبوعات)
python3 tools/sweep.py       # يصوّر 8 صفحات × 4 مقاسات ويقيس أي تجاوز أفقي
```
يتطلب Playwright (`pip install playwright && playwright install chromium`).

## أدوات الحصة: الأساس العلمي
صُمّمت لتوافق ما تُجمع عليه المعايير الدولية للوقاية (مكتب الأمم المتحدة المعني بالمخدرات والجريمة ومنظمة الصحة العالمية): التفاعل والتدرّب على المهارات، وتصحيح التصورات الخاطئة عن الأقران، والجلسات التذكيرية اللاحقة، وإشراك الشباب في صناعة الرسالة، وتجنّب التخويف. معظم الأدلة مأخوذ من برامج مدرسية في أمريكا وأوروبا، فيُنصح بتجربتها وقياس أثرها بالاختبارين القبلي والبعدي.
